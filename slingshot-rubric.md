Slingshot Hackathon Evaluation Criteria:

Code Quality: Code must be modular, follow DRY principles, include comprehensive docstrings/comments, and adhere to strict linting standards (PEP 8 for Python, ESLint for React).

Security: No hardcoded secrets. Must implement input sanitization, rate limiting, secure headers (CORS/Helmet), and robust authentication.

Efficiency: Optimized database queries (no N+1 problems), minimal Docker image sizes, and optimized frontend asset loading.

Testing: High test coverage (>80%) utilizing unit and integration tests for both frontend and backend.

Accessibility (a11y): Frontend must pass WCAG 2.1 AA standards (ARIA labels, keyboard navigation, color contrast).

Google Services: Deep integration with Google Cloud ecosystem (e.g., Cloud Run, Firebase, Cloud Storage, Cloud SQL).
